Pseudocódigo do Pipeline YOLOv8

INÍCIO

1. Configurar Hardware
    Verificar se existe GPU disponível.
    Se existir:
        Utilizar GPU para acelerar o treinamento.
    Senão:
        Utilizar CPU.

2. Configurar Ambiente
    Instalar biblioteca Ultralytics.
    Verificar se todas as dependências foram instaladas corretamente.

3. Conectar ao Google Drive
    Montar o Google Drive.
    Utilizar o Drive para armazenar datasets e resultados.

4. Preparar Dataset
    Definir caminhos do dataset.
    Verificar se o dataset já está disponível na máquina virtual.

    Se NÃO estiver disponível:
        Copiar arquivo ZIP do Google Drive.
        Descompactar dataset.
        Ler arquivo data.yaml.

    Senão:
        Utilizar o dataset existente.

5. Preparar Treinamento
    Remover arquivos de cache antigos.
    Desabilitar ferramentas externas de monitoramento.
    Criar uma pasta com data e hora para salvar os resultados do treinamento.

6. Configurar parâmetros de treinamento

    Definir:
        Modelo YOLO a ser treinado.
        Número de épocas.
        Batch size.
        Configuração de cache.
        Quantidade de processos (workers) para carregamento do conjunto de dados.

    Manter os demais parâmetros com os valores padrão da biblioteca Ultralytics.

7. Treinar Modelo
    Carregar o modelo YOLO.
    Ler imagens de treinamento.
    Executar treinamento durante todas as épocas.

    A cada época:
        Atualizar os pesos da rede.
        Validar desempenho.
        Salvar métricas.

    Ao final:
        Salvar o melhor modelo (best.pt).

8. Avaliar Modelo
    Carregar o arquivo best.pt.
    Executar inferência utilizando o conjunto de testes.
    Calcular métricas como:
        Precisão
        Recall
        MAP (Mean Average Precision)
        Matriz de confusão
        Tempo de inferência

9. Exibir Resultados
    Localizar imagens geradas pelo treinamento.
    Mostrar gráficos como:
        Curvas de perda (Loss)
        Curvas de precisão
        Curvas de recall
        Matriz de confusão
        Curva Precision-Recall
        Resultados das predições

FIM
